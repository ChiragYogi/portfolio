# Chirag Goswami — Portfolio

Personal portfolio site for Chirag Goswami, Android Developer.

## Stack

- TanStack Start
- React 19 + TypeScript
- Tailwind CSS v4
- Radix UI / shadcn-style components

## Development

```sh
npm install
npm run dev
```

Runs at [http://localhost:8080](http://localhost:8080).

## Build

```sh
npm run build
```
